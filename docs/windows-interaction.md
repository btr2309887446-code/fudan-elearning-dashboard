# Windows 交互反馈精修

本轮保留现有导航和业务功能，统一按钮、任务行、输入框、页签、对话框和分隔线的交互反馈。

## 本机体验

[交互短录屏](screenshots/windows-interaction.mp4) 展示真实窗口下的新建、保存失败与重试、完成撤销、列表与月历切换。画面先逐帧采集，再按实际时间间隔离线编码，没有加速动画。

- 正常演示：`npm run demo`。
- 慢请求和失败演示：`npm run demo:interaction`。每次使用新的临时虚构账号，首次保存延迟 600ms 后故意失败，重试成功；不会读取或修改正式账号数据。
- 建议体验：任务 → 新建 → 保存失败 → 重试 → 完成 → 撤销 → 列表/月历切换 → 课程页签键盘切换。

## 交互约定

- 悬停和按压 120ms，菜单与对话框 160ms，内容和行退出 200ms。主要按钮轻微下沉，普通列表不缩放。
- 保存成功后才改变任务状态；失败保留输入和选择，并显示可重试提示。处理中禁用重复提交。
- 完成任务先展示完成状态，再从待处理列表收起；撤销会写回本地数据。批量变更沿用现有原子保存：整批成功或整批失败，不虚构部分成功。
- 对话框打开聚焦标题，关闭恢复触发位置；窄窗口打开详情后聚焦返回按钮。课程页签支持方向键、Home 和 End。
- 详情、页签和列表/月历切换使用可取消的短过渡。系统减少动态效果时停用位移、缩放和 CSS 动画。
- 下载仅展示主进程提供的真实进度，无进度时显示准备中；异常后解除忙碌状态并保留错误。
- 登录验证码刷新可通过键盘操作，图标按钮有可访问名称。

## 验证

`npm run typecheck`、`npm test`、`npm run test:workspace-ui`。

界面测试使用真实 Electron 与隔离演示目录，新增慢保存、首次失败、重复点击、输入保留、完成撤销、焦点恢复、快速切换、页签键盘操作和减少动态效果场景。原有 5,000 项搜索、深浅色、800×600／1366×768／1920×1080、125%／150% 缩放场景继续执行。

测试专用的 IPC 延迟和失败包装位于 `scripts/feedback-main.cjs`，正式入口不加载它。录屏同样使用该虚构账号演示，不包含真实学校数据。

这次交付为本地源码与演示构建；此前的 0.10.0 安装包不包含本轮精修。真实学校登录和真实下载服务本轮不重复联网验证。
