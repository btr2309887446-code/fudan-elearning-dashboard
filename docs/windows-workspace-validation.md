# Windows 0.10.0 工作区验收记录

验证日期：2026-10-19。桌面代码与安装包均在 Windows 本机构建；所有界面截图使用隔离目录中的虚构数据。

## 已验证

- `npm run typecheck`：主进程、preload、领域层、React 类型检查通过。
- `npm test`：现有文件、摘要、无需提交、刷新、下载、缓存测试通过；新增任务、变化和持久化测试通过。
- 共享日期用例：闰年与平年月末、每周多日、跨年每日重复；TypeScript 通过，Swift 测试读取同一份 JSON。
- 任务：单次改期、将未来期次移入当前范围、每期完成/子任务独立、本次及以后删除/编辑、最多五个提醒、手动截止覆盖与恢复最新学校时间。
- 数据：按学校账号隔离；损坏文件不覆盖；写入备份失败保留原文件；错误账号 IPC 被拒绝。
- 同步：作业请求失败保留旧行及成绩汇总；失败和复用不推进变化基线；首次基线不发历史事件；零分、撤回、重复同步、180 天/2,000 条裁剪。
- 提醒计算：唤醒只补最近 24 小时；同一任务多个漏发提醒合并；已完成不提醒；已发标记避免重复。
- 5,000 个普通个人任务统一视图生成约 3 ms（本机单次测量，非跨设备性能保证）。列表分段呈现，每批 100 条。额外 5,000 项 Electron 场景验证只挂载 100 行，搜索指定任务并勾选成功（测试阈值 1 秒，包含等待 React 更新）。
- `node scripts/test-workspace-ui.mjs`：十组真实 Electron 自动化场景通过，包括新建、子任务勾选、完成、删除确认/取消、手动截止/恢复、月历、账号不匹配拒绝。
- 布局：1366×768、1920×1080、800×600，以及 125% 和 150% 缩放场景通过；缩放时至少保留 800×600 逻辑窗口。窄窗口详情替换列表，无页面水平溢出。
- 浅色和深色截图已检查。`Ctrl+N` 打开编辑对话框、`Esc` 关闭、`Ctrl+F` 聚焦搜索已实际操作。
- 今日及作业详情页 axe WCAG 2 A/AA 扫描：0 个确定违规；2 个导航符号的颜色需要人工判断，符号与对应文字使用同色。
- `node scripts/test-workspace-lifecycle.mjs`：开发程序和 `release/win-unpacked/Fudan-eLearning-Dashboard.exe` 均通过关闭留托盘、恢复窗口、真正退出；Windows API 报告支持通知。
- `npm run dist`：生成 x64 NSIS 安装包，App ID 保持 `cn.edu.fudan.elearning.dashboard`。
